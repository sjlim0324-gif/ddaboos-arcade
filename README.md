# 따부스 오락실

따뜻한 부동산 스터디(따부스)의 **팀 대항 미니게임 + 경품 추첨** 웹앱입니다.
노트북 한 대와 큰 화면(TV·빔프로젝터), 참가자 스마트폰만 있으면 돼요. 설치·회원가입·서버가 필요 없고 GitHub Pages만으로 동작합니다.

| 페이지 | 용도 |
|---|---|
| `index.html` | 시작 화면 |
| `host.html` | 진행 화면. 노트북에서 열어 큰 화면에 띄우세요 |
| `play.html` | 참가자 화면. 폰으로 QR을 찍으면 열려요 |
| `draw.html` | 경품 추첨. 폰 없이 큰 화면만 있으면 돼요 |

## GitHub Pages에 올리기

1. GitHub에서 새 저장소를 만드세요 (공개 저장소).
2. **Add file → Upload files**를 누르고, 이 폴더 안의 파일을 모두 끌어다 놓은 뒤 커밋하세요.
3. **Settings → Pages**에서 *Source: Deploy from a branch*, *Branch: main / (root)*를 고르고 저장하세요.
4. 1~2분 뒤 `https://아이디.github.io/저장소이름/` 주소로 열립니다.

## 진행 방법

1. 노트북 크롬에서 **게임 진행하기**를 누르면 큰 화면에 참가 QR과 방 코드 5자리가 떠요.
2. 팀 대표가 폰으로 QR을 찍고 팀 이름을 만들어요. 팀원은 같은 팀을 고르면 돼요. 팀 점수는 팀원 기록의 평균이에요.
3. 게임을 고르고 **Space**를 누르면 게임 소개 → 3·2·1 → 실시간 중계 → 시상대 순서로 진행돼요.
4. 마지막에 **최종 순위 발표**를 누르면 꼴찌부터 한 팀씩 공개하고, 우승팀은 왕관과 색종이로 마무리돼요.

단축키: `Space`/`Enter`/`PageDown`은 다음(PPT 리모컨도 됩니다), `←→`는 게임 고르기, `Q`는 참가 QR 크게 보기, `F`는 전체 화면, `S`는 설정, `Esc`는 뒤로예요.

## 미니게임 8종

연타왕 · 10초를 멈춰라 · 순간포착 · 암산 레이스 · 색깔 함정 · 따부스 두더지 · 숫자 사냥 · 부동산 OX 퀴즈

- 점수: 게임 순위대로 `전체 팀 수 − 순위 + 1`점을 받아요. 동점이면 같은 순위, 불참하면 0점이에요.
- 같은 판에서는 모든 폰에 같은 문제와 출현 순서가 나와요.

## 진행 보조 (설정 · S)

- 새 팀 만들기 허용/차단, 팀 이름 변경·삭제, 팀 미리 만들기
- 점수 보정(장기자랑·응원상 등), 직전 게임 결과 취소, 점수 초기화
- **가상 팀(리허설)**: 혼자서도 전체 흐름을 연습할 수 있어요
- 노트북을 새로고침해도 팀과 점수가 유지되고, 폰은 자동으로 다시 연결돼요.

## 경품 추첨 3종

돌림판 · 슬롯머신 · 스포트라이트

- 경품을 `커피 쿠폰 x5`처럼 적으면 위에서부터 차례로 추첨해요. 당첨자는 자동으로 제외돼요.
- **자리에 없음 → 다시 뽑기**를 누르면 그 사람을 빼고 같은 경품을 다시 뽑아요.
- **엑셀용 복사**로 당첨자 목록을 복사할 수 있어요.
- 당첨자는 먼저 공정한 난수로 정해지고, 연출은 그 결과에 맞춰 멈춰요. 후보가 많으면 "본선 진출" 연출을 거쳐요.

## 연결 방식

폰과 진행 화면은 공개 MQTT 중계 서버 두 곳(`broker.emqx.io`, `broker.hivemq.com`)을 동시에 써서 연결돼요. 팀 이름과 점수는 무작위 방 코드로 구분돼 이 서버를 거쳐 가요.
진행 화면 오른쪽 위가 `● 접속 N대 · 중계 2/2`면 정상이에요. 회사·행사장 와이파이가 막을 수 있으니 **행사장 인터넷으로 미리 리허설**하세요.

- `?net=local`: 같은 브라우저의 탭끼리 테스트할 때 써요 (인터넷 없이 확인용)
- `?mqtt=wss://주소`: 직접 운영하는 브로커를 쓸 때 써요

## 사용한 라이브러리

- `vendor/mqtt.min.js`: MQTT.js 5 (MIT)
